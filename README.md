# VR180 SBS Viewer (WebXR)

Meta Quest 3 のブラウザで動く VR180 / SBS 画像ビューア。`index.html` 1ファイルで完結（Three.js は CDN から読み込み）。
画像はブラウザ内でだけ読み込まれ、どこにもアップロードされません。

## Quest で使う

WebXR は **HTTPS** でしか動かないので、`index.html` を HTTPS で配信します。いちばん簡単なのは GitHub Pages です。

1. GitHub にリポジトリを作り、`index.html` を置く
2. Settings → Pages → Branch: `main` / root を選んで保存
3. Quest のブラウザで `https://<ユーザー名>.github.io/<リポジトリ名>/` を開く
4. 「画像を開く」で Quest 内の画像を選び（複数選択可）、「VRで見る」を押す

画像は USB 接続やファイル転送で Quest の `Download` などに入れておきます。

## PC で動作確認

```
powershell -ExecutionPolicy Bypass -File serve.ps1
```

`http://localhost:8080` を開くと 2D プレビューで確認できます（ドラッグで見回し、ホイールでズーム）。

## 機能

- 投影方式：正距円筒（VR180 / 360）・魚眼（等距離射影）・平面スクリーン
- 配置：左右 SBS / 上下 TB / モノ（縦横比から自動判定）
- 逆視（左右入れ替え）、シフト（輻輳）、上下ズレ補正
- ズーム、撮影画角、前後位置（球面）／距離・画面幅・高さ（平面）
- 向き（左右・上下・傾き）、グリップでつかんで移動、リセンター
- 3DoF 固定（頭を動かしても映像がずれない）
- 明るさ・コントラスト・彩度
- スライドショー、次の画像の先読み
- VR 解像度（フレームバッファ倍率）
- 設定はブラウザに自動保存

## Quest コントローラー

| 操作 | 機能 |
|---|---|
| 右スティック 左右 | 前／次の画像 |
| 右スティック 上下 | ズーム（球面）／距離（平面） |
| 左スティック 左右 | シフト |
| 左スティック 上下 | 上下ズレ補正 |
| A / Y | メニュー表示切替 |
| B | 逆視 |
| X | リセンター |
| グリップ | つかんで表示位置を移動 |
| トリガー | メニュー操作（何もない所で押すとメニュー開閉） |

ハンドトラッキングではピンチがトリガーの代わりになります。
